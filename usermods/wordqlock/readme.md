## Setup
### set LED count to 114 in Config -> LED Preferences
### configure a matrix for the clock face (if you want all beautiful matrix effects):
   - choose 2D Matrix in Config -> 2D Configuration
   - the only relevant settings are the dimensions (WxH): 11 x 10
### create segments 
  - face
  - dots
  - background
### save the segments to a preset (e.g. "startup") and note the ID
### set that preset as the startup preset
### Under Info is an easily accessible button to toggle the wordclock (will not be saved upon reboot)
